Shorts Uploader

개인용 유튜브 쇼츠 업로드 도구 · A personal YouTube Shorts upload tool

소개

Shorts Uploader는 운영자 한 명이 자신의 컴퓨터에서만 사용하는 개인용 도구입니다. 운영자가 직접 편집하고 검수한 동물 쇼츠 영상을 운영자 본인의 유튜브 채널에 업로드하고 공개 일정을 예약합니다.

  • YouTube Data API v3를 사용해 운영자 본인 채널에만 영상을 업로드합니다.
  • 다른 사용자의 계정에 접근하거나 다른 사용자에게 서비스를 제공하지 않습니다.

About

Shorts Uploader is a personal tool used by a single operator on their own computer. It uploads short animal videos, edited and reviewed by the operator, to the operator's own YouTube channel and schedules their publication using the YouTube Data API v3. It does not access other users' accounts or provide services to other users.
